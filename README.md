# Banana — Flagship Ecosystem & Storefront (Netlify Bundle)

**Designed & Engineered by Tamojit Roy**

## Included Files
- `index.html`: Self-contained responsive production application with embedded studio imagery, custom SVG Banana favicon, interactive 3D/finish switchers, Camera Control zoom simulator, Web Audio API acoustic demo, Side-by-Side hardware comparison matrix, Trade-In estimator, and Banana Pay checkout flow.
- `favicon.svg`: Standalone vector Banana emblem icon.
- `site.webmanifest`: Progressive Web App (PWA) metadata manifest.
- `netlify.toml` & `_redirects`: Zero-configuration Netlify routing and HTTP response headers.

## How to Deploy on Netlify
1. **Drag & Drop (Fastest)**: Extract this `.zip` archive and drag the extracted folder directly into [app.netlify.com/drop](https://app.netlify.com/drop).
2. **Netlify CLI**: Run `netlify deploy --prod --dir=.` from inside the extracted folder.
